# StickerSit — AI Sticker Pack Maker

Photo → 6 consistent reaction stickers (transparent PNG, ZIP download) + text-to-sticker generator.

## Deploy
Auto-deploys to Vercel from `main` (project: ai-sticker-maker).

## Local dev
```
npm install && npm run dev
```

## Test
```
npm run test:run        # unit (vitest)
node scripts/e2e-pack-local.mjs   # browser e2e (needs dev server + real API key)
```
