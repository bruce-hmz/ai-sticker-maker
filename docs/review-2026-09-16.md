### 3.1 判定信号

**Free utility 信号：**

- 单次使用为主：GA4 新用户占比 __%，returning 占比 __%（GA4 默认 client_id 口径）
- 每会话包数集中在 1：sessions 与 generation_started 数量比 __
- 流量几乎全为 Organic Search 长尾
- §4 付费意愿信号池全空

**Monetizable consumer 信号：**

- returning 用户中有 generation_started 的比例 __%（回访产生第二次生成）
- `single_sticker_regenerated` 率 __%（对单张反复重做 = 对结果质量在意）
- `packType=reaction-resume` 出现次数 __（愿重新上传照片补完 = 投入沉没成本）
- 评论区 / 邮件出现"多少钱 / 能高清吗 / 能打印吗"
- 用途问卷（§4）中 print_physical / personal_chat 为主
- GSC 中 consumer 意图词先到（"my pet sticker" 类）

**Creator opportunity 信号：**

- 单一会话内 generation_started ≥ 2（多包连做的批量行为）
- GSC query 或分发评论区出现：etsy / sell / sticker pack creator / commercial use
- 邮件 / 反馈问 API、风格一致性、商用授权
- 用途问卷（§4）中 resell / client_work 占比可观

| 事件 | `wtp_probe_viewed` + `wtp_probe_clicked`，属性 `probeType=use_case`、`option`（personal_chat / print_physical / resell / client_work / other） | 同左，`probeType=pricing_door`、`pricePoint`（free / 1.99 / 4.99 / 9.99_plus） |

| 诚实性 | 无付费暗示 | 明示 coming soon + "Just research — nothing to buy today"，无假 checkout |

读数方式（9/16）：

- 定价卡：`wtp_probe_clicked` 按 pricePoint 拆 ÷ viewed = 价格敏感度曲线。free 占比高且 4.99 以上近零 → consumer 付费证据弱；1.99–4.99 有可观占比 → §3.2 的 consumer 方向拿到第一份硬证据
- 问卷：personal_chat / print_physical → consumer 证据；resell / client_work → creator 证据（绝对值再小，出现即记入 §3.2）

## 5. 渠道归因纪律（SEO vs 视觉分发）

- 已发 Pinterest pin 的链接是裸域名（见 `promo-kit.md`）：平台允许编辑 pin 目标链接的就补 UTM；**不能编辑的保留原 pin，不删掉重发**——已有曝光比归因干净更重要。
- UTM 规范（此后每条外发链接照此执行）：`utm_source=pinterest`、`utm_medium=social`、`utm_campaign=promo_2026-09`、`utm_content=<pin 编号>`（其他平台换 source）。
- 无 UTM 兜底：GA4 默认 channel grouping 可粗分 Organic Search / Organic Social / Referral；精确归因靠 UTM。
